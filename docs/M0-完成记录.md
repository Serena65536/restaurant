## 踩到的 6 个坑（都已解决，写在这里免得下次重踩）

1. **PowerShell 5.1 读 BOM-less UTF-8 脚本会乱码** → 所有 `.ps1` 只用 ASCII 注释，中文只放在 `.md` 和 `.js` 里。
2. **RN CLI 用 piped stdio 调 `npm init`，被沙箱判 EPERM** → 改成自己从 `@react-native-community/template` 包组装工程（`scripts/assemble-app.mjs`），结果完全可复现。
3. **RN CLI 把缓存写到 `%LOCALAPPDATA%\Temp`** → 用环境变量把 `LOCALAPPDATA`、`TEMP` 指到工作区。
4. **`ANDROID_SDK_HOME` 和 `ANDROID_USER_HOME` 同时存在，AGP 直接拒绝构建** → 只留 `ANDROID_USER_HOME`。
5. **`local.properties` 里的 SDK 路径用了正斜杠，和 `ANDROID_HOME` 字符串不一致** → AGP 按字符串比较，改成和 env 完全一样的转义反斜杠写法。
6. **Gradle 文件监听线程被沙箱拒绝（error = 5）** → `org.gradle.vfs.watch=false`，不影响构建。
