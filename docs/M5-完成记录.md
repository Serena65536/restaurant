# M5 完成记录（2026-11-05）

## 这一版新增

1. **退出登录 / 切换账号（顾客和店主都有）**
   - 顾客：点餐页右上角「账号」→ 面板显示手机号 → 「退出登录 / 切换账号」→ 回到身份选择
   - 店主：管理首页右上角「退出登录」→ 回到身份选择
   - 退出只清手机本地 token，**服务端数据一条不删**；用原手机号重新登录，订单和菜品原样还在
   - 店主 token 与顾客 token 分开存，互不影响

2. **店主清零营业额**
   - 管理首页累计营业额旁「清零」按钮 → 二次确认 → 从 0 重新计
   - 实现方式：记一条「支付流水 id 水位线」（`settings.revenue_reset_payment_id`），统计只算水位线之后的收款
   - 历史订单、支付流水、订单列表一条不删；「今日营收」不受影响（它按自然日统计）

## 两次踩坑记录

1. **营业额清零后算错**：最初用「时间戳比较」（`paid_at >= reset_at`），清零和付款在同一秒发生时会被判成「清零前」，且两处时间格式一个是 `T` 分隔、一个是空格分隔，字符串比较直接错位。改成 **支付流水自增 id 水位线**后彻底不再依赖时间精度。
2. **`AccessibilityInfo` / 弹窗**：本轮无新坑，账号面板沿用已有 Modal 模式。

## 已知限制（都是刻意保留的）

- 支付是模拟的：真实收款要营业执照 + 微信商户号 / 支付宝签约，替换 `payments.mjs` 里的回调入口即可
- 临时隧道域名每次重启会变，且免费 quick tunnel 无 SLA
- APK 用 debug 证书签名（方便覆盖安装），不是上架包
- 数据库是单文件 SQLite（`server/data/app.db`），适合演示
- 所有数据集中在一台电脑上，电脑关机服务就停
